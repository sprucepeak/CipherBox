# CipherBox

**CipherBox** 是一款体积小巧、操作简单且具备极高安全性的现代化文件加密工具。本项目采用 Go 语言结合轻量原生的图形界面开发框架，专注于为用户提供最纯粹、可靠、易用的文件加密方案。

CipherBox 核心采用先进的 **XChaCha20** 对称加密算法与 **Argon2id** 密钥派生函数，为您的敏感数据提供银行与军工级别的加密防护。默认生成 `.sbx` 专属安全加密卷。

---

## ✨ 核心特性

- **极简易用**：拖入文件/文件夹 -> 输入密码 -> 点击加密/解密，几秒内即可上手。
- **轻量原生架构**：采用 `mygo` 原生 UI 与 `purego` 系统 API 调用，无需繁重的 WebView 或 C 编译器绑定，启动极速、资源开销极小。
- **顶级密码学与架构保障**：
  - 加密与认证：基于现代 **XChaCha20-Poly1305** 流式 AEAD 认证加密，杜绝块乱序与篡改隐患。
  - 密钥派生：高强度抗 GPU/ASIC 破解的 **Argon2id**。
  - 零复杂状态机：摒弃传统多重级联与 60GiB Nonce 溢出检测，性能直达磁盘 I/O 极限。
- **专属格式与向下兼容**：默认输出 `.sbx`（CipherBox 专属安全卷）。
- **便携与免安装**：单二进制文件运行，无需管理员权限，无后台服务或常驻守护进程。
- **抗量子计算威胁**：全套私钥密码学体系，免受量子计算破解风险。
- **丰富高级功能**：
  - **密码生成器**：内置密码学安全的强密码生成器。
  - **密钥文件（Keyfiles）**：支持使用任意文件作为密钥凭据，支持多密钥文件协同授权及解密顺序校验。
  - **偏执模式（Paranoid Mode）**：启用更严苛的 Argon2id 派生参数（1GiB 内存 / 8 轮 / 8 线程），极大推高暴力破解门槛。
  - **Reed-Solomon 矩阵纠错**：基于硬件加速的现代 RS 纠错码（10+2 冗余机制），支持高达 20% 损坏恢复与精确定位。
  - **分块拆分（Chunking）**：支持将超大文件自动切分为指定大小的分卷（`.sbx.0`, `.sbx.1`...），便于网盘与外部介质传输。
  - **可否认性加密（Plausible Deniability）**：密文无任何特征头，与纯随机数据完全一致，防止窥探者察觉文件已被加密。
  - **内置压缩**：可选 Deflate 压缩机制，减少归档体积。
  - **递归批量处理**：支持对多层级文件夹内各文件进行递归独立加解密。

## 🛠️ 从源码构建与运行

CipherBox 基于原生 Go 开发，构建极为简便直接。

### 1. 安装开发环境

- 安装 Go（推荐 Go 1.22+ 或最新版，下载地址：[go.dev/dl](https://go.dev/dl/)）。

---

### 2. 获取代码与依赖

```bash
git clone <本仓库地址>
cd <项目目录>
go mod download
```

---

### 3. 编译二进制文件

直接运行标准 `go build` 即可编译：

- **Windows**（生成无控制台窗口的独立 GUI 程序）：

  ```bash
  go build -ldflags="-s -w -H=windowsgui" -o CipherBox.exe .
  ```

- **Linux / macOS**：

  ```bash
  go build -ldflags="-s -w" -o CipherBox .
  ```

编译完成后即可在当前目录下获得 `CipherBox.exe`（或 `CipherBox`）可执行文件。

## 🚀 使用指南

### 基础加解密

1. **加密**：
   - 将需要加密的文件或文件夹拖入 CipherBox 窗口。
   - 输入访问密码（或点击右上角生成强密码）。
   - （可选）根据需求勾选密钥文件、偏执模式或分块等选项。
   - 点击 **加密**，等待处理完成即可生成 `.sbx` 加密卷文件。
2. **解密**：
   - 将加密后的文件（`.sbx`）拖入 CipherBox 窗口。
   - 输入正确的密码并选择相应的密钥文件（如有）。
   - 点击 **解密** 恢复原始数据。

## 🔒 密码学与安全声明

1. **宿主环境安全**：CipherBox 设计目标为保证加密数据在存储与传输介质上的静态安全性（Data-at-Rest Security）。加解密操作依赖宿主系统的信任链，若宿主机器已被植入键盘记录器或恶意木马，任何加密软件都无法提供安全保障。
2. **安全删除**：CipherBox 沿用操作系统标准的文件删除操作。在配备磨损均衡（Wear Leveling）算法的现代 SSD、NVMe 等闪存介质上，传统“文件覆写粉碎”已被证明无法可靠覆盖特定底层扇区。因此，建议在敏感存储介质上配合整盘加密或物理销毁策略。
